# AGENTS.md — указатель для AI-агентов

Полные правила проекта InfCanvas, карта модулей и инструкции по тестам лежат в `.ai/`:

1. `.ai/AGENTS.md` — правила, инварианты (граф слоёв, бинарный формат доски), ловушки.
2. `.ai/docs/PROJECT_MAP.md` — модули, зависимости, «куда что класть».
3. `.ai/docs/TESTING.md` — стек тестов и команды.
4. `.ai/skills/android-module/SKILL.md` — процедуры «новая кисть / инструмент / тип объекта / формат».

Перед правками кода прочитай пункты 1–3; для задач про кисти/инструменты/формат — пункт 4.
